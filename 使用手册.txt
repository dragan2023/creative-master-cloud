【一、运行前的准备工作】

1. 系统要求
   - 操作系统：Windows 10/11
   - 内存：至少 8GB RAM（推荐 16GB）
   - 硬盘：至少 10GB 可用空间

2. 必需软件（需自行安装）
   
   软件名称    版本要求    下载地址
   ─────────────────────────────────────────────────────────────────────
   Python      3.10+      https://www.python.org/downloads/
   Node.js     20.0+      https://nodejs.org/zh-cn/download
   
   重要提示：安装 Python 时请勾选 "Add Python to PATH" 选项！

3. 可选组件
   - Visual C++ Redistributable（推荐安装，用于AI模型加速）
     下载地址：https://aka.ms/vs/17/release/vc_redist.x64.exe
   - NVIDIA显卡驱动（如有NVIDIA显卡，可启用GPU加速）

4. 验证安装
   打开命令提示符（Win+R 输入 cmd），执行：
   
   python --version    # 应显示 Python 3.10.x 或更高
   node --version      # 应显示 v20.x.x 或更高

【二、软件主要功能介绍】

全能创意大师是一款基于AI的创意内容生成平台，支持以下功能模块：

┌─────────────┬──────────────────────────────────────────────────────────┐
│ 模块名称     │ 功能描述                                                  │
├─────────────┼──────────────────────────────────────────────────────────┤
│ 短视频脚本   │ 生成抖音、快手、B站、小红书等平台的短视频脚本             │
│ 剧本大纲     │ 生成院线电影、网剧、短剧等剧本大纲和分场剧本              │
│ 小说创作     │ 生成小说大纲、章节大纲、正文内容，支持多种题材类型        │
│ 平面广告     │ 生成品牌广告文案和AI绘画提示词                            │
│ TVC广告脚本  │ 生成电视广告脚本和AI视频提示词                            │
│ 原创IP计划   │ 一键构建完整角色IP档案，支持商业潜力分析                  │
└─────────────┴──────────────────────────────────────────────────────────┘

核心特性：
- 多模型支持：DeepSeek、OpenAI、Google Gemini、通义千问、豆包等
- 知识库增强：上传专业文档，AI自动检索相关知识优化生成结果
- GraphRAG技术：采用知识图谱增强检索，深入理解文档内容
- 流式输出：实时展示生成过程，提升交互体验
- 两阶段大纲生成：全局大纲 → 单元概述，更专业的创作流程
- 联网搜索：支持博查AI、百度搜索，可配置用户专属API Key

【三、基本使用方法】

1. 启动服务
   
   方式一（推荐）：双击运行 start.bat
   - 自动检测环境、安装依赖、启动前后端服务
   - 浏览器会自动打开 http://localhost:5173
   
   方式二：分别启动前后端
   - 后端：双击 run-backend.bat
   - 前端：双击 run-frontend.bat

2. 停止服务
   - 方法一：在运行窗口按 Ctrl + C
   - 方法二：双击运行 stop.bat

3. 访问地址
   
   服务类型    地址
   ────────────────────────────────────────
   前端界面    http://localhost:5173
   后端API     http://localhost:8000
   API文档     http://localhost:8000/docs

4. 基本操作流程
   
   步骤1：配置AI模型API Key（右上角 → API Key管理）
   步骤2：选择功能模块（短视频/剧本/小说/广告/IP计划）
   步骤3：填写创作参数，点击生成
   步骤4：查看结果，可复制、下载或重新生成

5. API Key配置
   
   支持的模型提供商：
   
   提供商      获取方式                              推荐模型
   ──────────────────────────────────────────────────────────────────
   DeepSeek    https://platform.deepseek.com/        deepseek-chat

   Google      https://aistudio.google.com/          gemini-1.5-pro
   通义千问    https://dashscope.console.aliyun.com/ qwen-max
   豆包        https://console.volcengine.com/ark    doubao-pro
   贞贞AI工坊  https://ai.t8star.cn/                 gpt-4o

6. 联网搜索配置（可选）
   
   支持的搜索服务商：
   
   服务商      获取方式                              说明

   博查AI      https://bocha.io/                    实时搜索、结构化结果
   百度搜索    无需配置（系统内置）                  基础搜索功能

【五、常见问题解答】

Q1: 首次启动很慢怎么办？
A: 首次启动需要安装依赖，这是正常现象：
   - Python依赖安装：约3-5分钟
   - Node.js依赖安装：约1-2分钟
   - 后续启动会快很多

Q2: 提示"端口被占用"怎么办？
A: 运行 stop.bat 或关闭所有窗口重新运行start.bat清理端口，或手动关闭占用端口的程序。
   后端默认端口：8000，前端默认端口：5173

Q3: 提示"Python未找到"怎么办？
A: 1) 确认已安装Python 3.10+
   2) 安装时勾选了"Add Python to PATH"，或手动将python加入PATH
   3) 重启命令行或重启电脑后再试

Q4: 生成结果不满意怎么办？
A: 1) 提供更详细的输入描述
   2) 尝试不同的AI模型
   3) 开启知识库增强功能
   4) 使用"重新生成"功能
   5) 使用"优化描述"功能优化输入

Q5: 如何备份数据？
A: 备份以下目录：
   - backend/data/creative_master.db  （用户数据）
   - backend/data/chroma/             （知识库向量数据）
   - backend/data/knowledge_graphs/   （知识图谱）

Q6: 知识库处理很慢怎么办？
A: 知识库处理需要下载AI模型，首次使用较慢。
   建议：
   - 使用DeepSeek等低价模型处理知识库
   - 在个人设置中关闭GraphRAG，使用传统向量检索

Q7: GPU加速如何启用？
A: 1) 确保已安装NVIDIA显卡驱动
   2) start.bat会自动检测GPU并安装对应版本PyTorch
   3) 无GPU也可正常运行，使用CPU版本

Q8: 如何查看错误日志？
A: 日志文件位置：backend/logs/
   - app_日期.log  （应用日志）
   - error_日期.log（错误日志）

Q9: 联网搜索返回0结果怎么办？
A: 1) 检查网络连接是否正常
   2) 在API Key管理中配置博查AI的API Key
   3) 确保API Key有效且有余额
