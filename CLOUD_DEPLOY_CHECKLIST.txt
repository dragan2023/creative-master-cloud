| backend/data/chroma/models/models--sentence-transformers--all-MiniLM-L6-v2/ | 嵌入模型 | ~90MB |

**注意**: 模型文件太大，不上传GitHub。部署时需要：
1. 本地下载后上传到服务器
2. 或在服务器上运行 `bash scripts/download-model.sh`（需设置代理）

## 七、部署步骤

### 步骤1: 推送代码到GitHub
```bash
cd "项目目录"
git add .
git commit -m "feat: 云端部署配置"
git push origin main
```

### 步骤2: 服务器克隆项目
```bash
git clone https://github.com/你的用户名/creative-master-cloud.git
cd creative-master-cloud
```

### 步骤3: 配置环境变量
```bash
cp .env.cloud .env
# 编辑.env，设置SECRET_KEY
nano .env
```

### 步骤4: 下载嵌入模型（如需代理）
```bash
export HTTP_PROXY=http://代理地址:端口
export HTTPS_PROXY=http://代理地址:端口
bash scripts/download-model.sh
```

### 步骤5: 执行部署
```bash
bash scripts/deploy.sh
```

## 八、关键修复说明

本次部署已包含以下修复：

1. **requirements.txt**: 添加了 `pysqlite3-binary` 和 `PyJWT`
2. **vector_store.py**: 添加了 pysqlite3 替换 sqlite3 的代码
3. **docker-compose.prod.yml**: 移除了过时的 `version` 字段
4. **nginx.conf**: 配置为HTTP模式（无SSL）
